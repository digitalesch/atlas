## [0.1.0-alpha.1] - 2026-08-07

### Added

* Initial Atlas compiler skeleton.
* Established project architecture.
* Created CLI with Typer.
* Added `doctor` and `version` commands.
* Introduced Rich-based console output.
* Added project documentation:

  * README
  * Manifesto
  * Contributing Guide
  * RFC system
* Defined the initial compiler philosophy.

### Notes

This is the first public milestone.

Atlas is currently focused on establishing its architecture and engineering principles. No machine generation or CAD export is implemented yet.
